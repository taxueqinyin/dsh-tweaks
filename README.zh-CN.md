# dsh-tweaks

给 [DeepSeek Harness](https://github.com/deepseek-ai)（简称 DSH）补两个小功能。

[English](README.md)

## 为什么需要它

DSH 官方的设置界面有两处不太顺手：

**一、想让模型看图，却没地方开。**
你在配置里手写的模型，默认全是纯文本模式 —— 哪怕这个模型其实支持看图。
想开启只能手动编辑配置文件，改完还不确定到底生效没有。

**二、长期偏好每次都要重说一遍。**
比如"用中文回答""别奉承我""先给结论"这类要求，每开一个新会话就得再交代一次，很烦。

## 装上之后

### 1. 模型的「图片输入」开关（设置 → 模型）

每个提供方卡片上会多出一块 **图片输入能力**，模型列表直接勾选就行。

- 勾上 → 这个模型可以接收图片
- 取消 → 回到纯文本

模型多的时候列表会自动折叠，不会占满屏幕。

### 2. 通用系统指令（设置 → 个性化）

一个文本框，**写一次，长期生效**。

里面的内容会出现在**每一次对话的最开头**，相当于给所有会话统一设了一条规则。例如：

> 始终用中文回答；先给结论再给理由；不要奉承，直接指出我的错误。

离开输入框自动保存（和原生设置项一样，没有保存按钮）。**留空则完全不生效。**

## 安装

```sh
dsh plugin --profile web add dsh-tweaks
```

装完**重启 DSH** 即可，不用改任何代码。

## 两点说明

- 图片开关只对**你自己手写的模型列表**生效。用官方模型目录、或自建网关的路由，面板管不到，需要直接改配置文件。
- 这个开关是"声明"而不是"检测"：给一个实际不支持看图的模型开了开关，发图时会被模型方拒绝。

## 开发

```sh
pnpm install
pnpm run build   # 打包
pnpm run watch   # 改代码时自动重新打包
```
